# 《销售报价 + 工时管理系统》开发教材（总览页）

> 这是一套面向**工业自动化 / 系统集成行业**的销售管理与报价系统 + 员工工时管理系统的完整教材。
> 三个代码库、一套共享数据库、一个真实部署在云端的生产应用。教材按章节分文件存放于 `docs/开发教材/` 目录，本页是**教材首页**：说明阅读方式、给出全章节索引与练习地图。

---

## 一、这套教材讲什么

| 维度 | 内容 |
|---|---|
| **代码库** | 预算应用 Budget（`D:\109-BudgetEstimate\BudgetEstimateApp`）、工时应用 TR（`D:\108-TimeRecording\frontend`）、共享后端（`D:\109-BudgetEstimate\backend`） |
| **技术栈** | React 19 + TypeScript/JavaScript + Ant Design 6 + Vite 8 · Node.js + Express 4 + PostgreSQL · Vitest |

| **适合** | 已掌握 HTML/CSS/JS 基础、想理解"一个完整业务系统是怎么搭出来的"的入门开发者 |

## 四、练习地图（一句话版）

```
练习0 跑起来（三库 + 数据库 + 登录）            → 建立全局观
练习1 改纯函数（给 calcDirectCost 补测试）       → 理解"纯函数 + 单测"
练习2 列表页加列（antd Table + 类型）            → 前端增改最小闭环
练习3 新增 CRUD 资源（前后端全栈）               → 掌握 crudRoutes + 四件套注册
练习4 加统计图表（SVG + useMemo 派生）           → 分析页模式
练习5 加权限控制（前后端双守卫）                 → 掌握权限体系
练习6 加审批类型（状态机全链路）                 → 最难、最有价值
练习7 共享函数立基准（测试 + bench）             → 质量文化
```

> 每个练习都给出：学习目标、前置知识、动手步骤、**参考示例代码**、验收标准、常见坑。

## 六、开始之前：三条最重要的心理准备

1. **这不是教学 Demo，是生产系统**。它有真实的鉴权、审批、审计、定时任务、部署与运维。每个"看似多余的检查"背后都是一次线上事故。
2. **代码里的 `// ⚠️ 编号 修复：原因` 注释是最珍贵的教材**。它们记录了"为什么这样写"，比教科书更真实。读代码时先读注释。
3. **不会一次读完**。按路线 A 读一遍建立骨架，之后遇到具体需求再回查对应章节。练习路线（17 章）会带着你把知识变成能力。
