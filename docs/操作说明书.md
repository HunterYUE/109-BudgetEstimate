# 销售报价与工时管理系统 操作说明书

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 发布日期 | 2026-10-19 |
| 适用系统 | 预算应用（Budget）、工时应用（Time Recording）、共享后端 |
| 适用对象 | 销售、方案、交付、审批、系统管理员及工时填报人员 |
| 文档性质 | 操作规范 |

## 1 系统概述

### 1.1 系统组成

系统由两个前端应用与一个共享后端组成。

| 组成 | 访问路径 | 职责 |
|---|---|---|
| 预算应用 | `/budget/` | 销售机会、报价编制、审批、交付、客户、物料、标签、分析、系统管理 |
| 工时应用 | `/timerecording/` | 工时填报、任务规划、工时统计、工时审核 |
| 共享后端 | `/api/v1/` | 统一认证、业务接口、数据库访问 |

### 1.2 业务主线

```
销售机会 → 蓝表分析 → 报价编制 → 审批 → 转交付 → 交付执行 → 销售/交付分析
```

工时线独立运行，与预算应用共用用户、成本中心与数据库。

### 1.3 财年与金额口径

| 项目 | 规则 |
|---|---|
| 财年 | 每年 7 月 1 日至次年 6 月 30 日；标识为 `FY` + 起止年份后两位，如 `FY2627` |
| 订单金额 | 归集至机会转交付月份，只归集一次 |
| 销售金额 | 归集至交付节点 15 完成月份，只归集一次 |
| 金额口径 | 明细、成本、机会金额按未税处理；报价汇总的预期总价、折后报价、项目利润按含税展示 |
| 折后报价 | 页面输入与数据库存储均为含税值；明细与单价按未税展示 |

## 2 登录与权限

### 2.1 登录

1. 打开系统地址，进入登录页。
2. 输入邮箱与密码。
3. 登录成功后进入可访问的首个模块。

密码长度为 8 至 128 个字符。连续登录失败会触发限速，15 分钟内最多尝试 20 次。

### 2.2 会话

- 登录凭证保存在 HttpOnly Cookie 中，有效期 24 小时。
- 关闭浏览器不会立即退出登录。
- 修改密码后，已签发的旧凭证立即失效。
- 退出登录会同时清除预算应用与工时应用的登录状态。

### 2.3 权限模型

权限以字符串数组直接分配给用户，不以角色单独决定。

| 规则 | 说明 |
|---|---|
| 任一命中 | 页面或操作要求多个权限时，持有其中任意一个即可访问 |
| 万能权限 | `全部查看权限` 可访问全部模块与写操作 |
| 前后端双守卫 | 前端控制入口与按钮显示，后端执行最终鉴权 |
| 角色 | `user`、`manager`、`director`、`admin`；主要用于工时系统与管理层级 |

### 2.4 跨应用访问限制

| 职务 | 允许访问 |
|---|---|
| 普通员工（非 director/admin） | 仅工时应用 |
| 销售经理（非 director/admin） | 仅预算应用 |
| 其他职务 | 按权限访问两个应用 |

## 3 仪表盘

路径：`/`。所需权限：`仪表盘查看`。

仪表盘展示以下内容：

| 区域 | 内容 |
|---|---|
| 概览卡片 | 销售、订单、利润、交付等关键指标 |
| 机会管道 | 近 3 个月各阶段机会数量 |
| 交付状态 | 已完成、进行中、已延期 |
| 节点执行 | 当月完成、当月执行、延期中 |

财年切换位于页面右上角。未来财年不显示数据。

## 4 销售管理

路径：`/opportunities`。读取权限：`销售机会管理`；写操作按动作分别校验。

### 4.1 列表与页签

| 页签 | 显示范围 |
|---|---|
| 销售信息 | 阶段为「信息」 |
| 销售线索 | 阶段为「线索」 |
| 销售机会 | 阶段为「机会、投标、议价、中标」 |

列表按销售编号升序排列。支持按阶段、状态、区域销售、预计定标日期筛选，并可按销售编号、客户名称、项目名称、销售员搜索。

### 4.2 新建机会

1. 在目标页签点击「新增信息 / 线索 / 机会」。
2. 填写客户名称、项目名称、金额、阶段、状态、销售员、竞争对手、预计定标日期、说明。
3. 保存。

规则：

- 销售编号由后端统一生成，格式为 `A{YYYY}-{MM}-{NNN}-S`。
- 项目名称创建后只读。
- 机会名下存在任一报价后，金额列锁定。
- 进入各阶段的时间由服务端按创建或推进时刻记录，客户端不可修改。

### 4.3 蓝表分析

蓝表用于评估机会赢率，在「销售线索」与「销售机会」页签点击赢率列进入。

蓝表包含以下维度：

| 维度 | 内容 |
|---|---|
| 预算 | 否决预算、预算金额 |
| 时间 | 时间计划、时间选项 |
| 定价 | 定价策略 |
| 定位 | 定位方式 |
| 反应 | 反应模式 |
| 策略 | 销售策略 |
| 目标 | 提升目标与目标支持度 |
| 角色 | EB、UB、TB、COACH 及影响力、支持度、需求契合度、关系 |

保存后，赢率自动计算并写回机会；角色与提升目标的关联随蓝表一并保存。

### 4.4 阶段推进

| 操作 | 说明 |
|---|---|
| 转线索 | 销售信息页签操作；阶段由「信息」推进至「线索」 |
| 转机会 | 销售线索页签操作；阶段推进至「机会」 |
| 机会页签内推进 | 可在机会、投标、议价、中标之间调整 |

阶段变更会记录进入时间；已进入的阶段时间不会被覆盖。

### 4.5 状态变更

| 状态 | 操作 | 说明 |
|---|---|---|
| 赢 | 赢单 | 选择赢单原因并保存 |
| 输 | 输单 | 选择输单原因，可指定赢家 |
| 冻结 | 冻结 | 选择冻结原因 |
| 过程中 | 恢复进行 | 清除原因与输单时间 |

状态写入以后端返回为准；保存失败时界面会恢复到保存前状态。

### 4.6 转交付

机会状态为「赢」且已存在报价时，可在操作列点击「转交付」。转交付将创建交付项目，机会标记为已终止，销售编号后缀由 `-S` 变为 `-E`。

同一机会只能转交付一次。已转交付的机会不可删除。

### 4.7 删除

- 未转交付的机会可删除。
- 存在交付项目的机会不可删除，须先删除对应交付项目。
- 已提交晋升审批且处于锁定状态的机会不可修改。

## 5 报价管理

### 5.1 报价列表

路径：`/quotations`。读取权限：`报价列表查看` 或 `报价编制`。

列表显示销售编号、客户、项目、版本、金额、利润率、审批状态与更新时间。支持搜索与排序。

### 5.2 新建报价

1. 从销售机会点击报价图标，或在报价列表新建。
2. 系统预填销售编号、客户名称、客户编码、项目名称、预计定标日期。
3. 填写项目信息并编制明细。
4. 保存后生成报价记录。

### 5.3 项目信息

项目信息包括客户名称、客户编码、销售编号、项目名称、项目范围、项目阶段、预计定标日期、项目布局、交付周期、付款条件、后缀、备注。

版本信息包括版本号、欧元汇率、税率、质保金比例、风险金比例、商业费用。

### 5.4 版本管理

- 每次保存按当前版本号写入版本记录。
- 修改版本号后保存，将创建新版本；组数据按版本隔离。
- 打开报价时按报价记录的版本号加载对应版本；版本不存在时中止加载并提示。
- 已通过或已驳回的版本再次保存时，状态自动降级为草稿，并提示需重新审批。
- 待审批版本在审批完成前不可保存。

### 5.5 设备组与固定组

| 类型 | 说明 |
|---|---|
| 设备组 | 可新增、删除、重命名；按界面顺序自动编号 |
| 集成控制 | 固定组 |
| 包装运输 | 固定组 |
| 项目交付 | 固定组 |
| 实施费用 | 固定组 |
| 其他 | 固定组 |

删除设备组后，需保存报价才会写入数据库；保存失败时删除不会生效。

### 5.6 明细与计算

明细字段包括类型、编码、描述、数量、单位、采购方式、单位成本、设计工时、装配工时、工时费率、毛利率、质保标记、备注。

| 计算项 | 公式 |
|---|---|
| 物料成本 | 单位成本 × 数量 |
| 设计成本 | 设计工时 × 设计工时费率 |
| 装配成本 | 装配工时 × 装配工时费率 × 数量 |
| 直接成本 | 物料成本 + 设计成本 + 装配成本，取整到个位 |
| 预期售价 | 直接成本 ÷（1 − 毛利率），取整到个位 |

编码不在物料库中时，编码列显示红色警示。保存与提交前会校验编码有效性。

### 5.7 汇总与利润

| 项目 | 计算口径 |
|---|---|
| 总直接成本 | 全部明细直接成本之和 |
| 质保基数 | 设备组与集成控制组中未标记质保的明细直接成本之和 |
| 质保费用 | 质保基数 × 质保金比例 |
| 风险费用 | 总直接成本 × 风险金比例 |
| 商业费用 | 手工录入 |
| 总成本 | 总直接成本 + 质保费用 + 风险费用 + 商业费用 |
| 预期总价 | 全部明细预期售价之和，含税展示 |
| 折后报价 | 手工录入，含税 |
| 折扣率 | （预期总价 − 折后报价）÷ 预期总价 |
| GP3 | （折后报价 − 总成本）÷ 折后报价，按含税口径计算 |

### 5.8 保存与提交

保存：

1. 校验客户名称、项目名称、项目范围、明细数量与编码。
2. 写入项目、版本、组、明细与报价摘要。
3. 已通过或已驳回的报价保存后转为草稿。

提交审批：

1. 报价必须已保存且存在明细。
2. 系统保存最新版本与组数据，写入报价状态为待审批。
3. 创建报价审批请求，页面转为锁定状态。
4. 提交失败时自动回滚为草稿，可修正后重新提交。

### 5.9 锁定规则

| 情形 | 状态 |
|---|---|
| 报价待审批 | 锁定 |
| 机会已中标且状态为赢 | 锁定 |
| 机会已终止或已转交付 | 锁定 |
| 报价已通过或已驳回且未签单 | 可编辑；保存后降级为草稿 |
| 以只读参数打开 | 锁定 |

### 5.10 导出

导出条件：

- 报价状态为已通过；
- 不存在未保存修改。

导出内容包含项目信息、组小计、明细行、含税汇总。零价明细同样导出。

## 6 审批管理

路径：`/approval`。所需权限：`审批管理`。

### 6.1 页签

| 页签 | 内容 |
|---|---|
| 草稿 | 尚未提交的报价、计划、成本、晋升草稿 |
| 待审批 | 状态为待审批的请求 |
| 已审批 | 状态为已通过或已驳回的请求 |
| 我的提交 | 当前用户提交的请求 |
| 全部 | 全部审批请求 |

### 6.2 审批类型

| 类型 | 提交方 | 通过后处理 |
|---|---|---|
| 报价审批 | 报价编制 | 报价与版本状态改为已通过；机会金额回写为报价金额 |
| 实施计划审批 | 交付管理 | 交付计划状态改为已通过；节点计划完成日写入初始基线 |
| 成本对比审批 | 交付管理/成本录入 | 交付成本状态改为已通过；实际成本生效 |
| 晋升审批 | 转线索/转机会 | 机会阶段推进至「机会」 |

### 6.3 审批与驳回

1. 在「待审批」页签选择记录。
2. 点击通过或驳回，填写意见。
3. 确认后提交。

规则：

- 同一实体同一类型只允许存在一条待审批请求。
- 审批人取自当前登录用户，不可代填。
- 已通过或已驳回的请求不可再次处理。
- 审批处理采用事务与行锁，重复点击只生效一次。

### 6.4 取消审批

仅待审批状态可删除。删除后：

- 报价审批：报价与版本恢复为草稿；
- 计划审批：计划状态恢复为草稿；
- 成本审批：成本状态恢复为草稿；
- 晋升审批：解除机会锁定。

已通过或已驳回的审批是审批历史，不可删除。

### 6.5 审批中的编辑限制

| 对象 | 限制 |
|---|---|
| 报价 | 金额、成本、利润率、编号、归属、关联机会不可修改 |
| 实施计划 | 节点不可修改 |
| 成本对比 | 实际成本不可修改 |

## 7 交付管理

路径：`/delivery`。读取权限：`交付管理`。

### 7.1 转交付

由销售机会发起。系统创建交付项目、复制机会与报价关联、初始化 15 个标准节点。

交付项目包含客户、项目名称、合同金额、关联报价、执行状态、计划审批状态、成本审批状态、实际总成本。

### 7.2 交付列表

显示销售编号、客户、项目、合同金额、执行状态、计划与成本审批状态、更新时间。支持搜索。

### 7.3 交付详情

详情页包含三个页签：

| 页签 | 内容 |
|---|---|
| 实施计划 | 15 个节点的计划日期、实际日期、状态、备注 |
| 成本对比 | 报价概算与实际成本逐项对比 |
| 附件 | 客户需求书、技术方案、技术协议、商务合同 |

### 7.4 节点管理

节点状态为待开始、进行中、已完成。

| 操作 | 规则 |
|---|---|
| 开始节点 | 写入实际开始日期 |
| 完成节点 | 写入实际完成日期 |
| 回退节点 | 保留原实际开始日期，清除完成日期 |

节点 15 为项目总结。将节点 15 置为已完成时，须满足：

1. 成本对比审批已通过；
2. 其余全部节点均已完成为已完成。

### 7.5 实施计划审批

1. 填写全部节点的计划开始与结束日期。
2. 保存计划。
3. 提交审批。

提交后节点冻结。审批通过时，节点计划完成日写入初始基线，用于延期判定；基线一经写入不再覆盖。

计划已通过后，仅持有 `交付管理` 或 `全部查看权限` 的用户可继续维护节点。

### 7.6 成本对比

成本对比表按类别列出概算与实际成本，计算偏差与偏差率。

1. 录入各项实际成本。
2. 至少录入一项大于 0 的实际成本。
3. 保存或提交审批。

规则：

- 实际总成本 = 当前报价组项的实际成本之和 + 质保费用；已不存在组项的历史孤儿数据不计入。
- 成本审批中不可修改实际成本。
- 成本审批通过后默认锁定；总监可解锁覆盖，覆盖操作记录审计日志。
- 报价数据未加载完成或加载失败时，不可提交审批。

### 7.7 附件

| 项目 | 规则 |
|---|---|
| 类型 | 客户需求书、技术方案、技术协议、商务合同 |
| 格式 | PDF |
| 大小 | 不超过 3 MB |
| 权限 | 上传、下载、删除均需 `交付管理` 或 `全部查看权限` |
| 删除 | 二次确认，不可恢复 |

### 7.8 完成项目

完成项目须同时满足：

1. 成本对比审批已通过；
2. 全部节点已完成。

点击「完成项目」时，系统先保存节点数据，再将项目状态置为已完成。项目状态为已完成后，是销售金额与财年归集的依据。

### 7.9 删除交付

存在待审批请求时不可删除。删除成功后，数据库记录与磁盘附件一并清除。

## 8 分析与报表

### 8.1 销售分析

路径：`/analysis`。所需权限：`销售分析`。

内容包括：

| 指标 | 口径 |
|---|---|
| 机会漏斗 | 按机会在财年内的活跃期统计 |
| 月度订单 | 转交付月份归集，含金额与概算利润 |
| 月度销售 | 节点 15 完成月份归集，含金额与实际利润 |
| 销售员排行 | 财年内机会金额、赢单金额与管道潜力 |
| 输单原因 | 按竞对、取消、放弃分组统计 |
| 加权 GP3 | 订单概算与实际交付分别加权 |
| 目标完成 | 年度目标、累计完成与累计利润 |

说明：

- 活跃期与财年有交集的机会可在多个财年重复统计。
- 订单金额与销售金额只归集一次，不跨财年重复。
- 已完成项目缺少实际成本时，累计利润显示「成本缺失」。
- 亏损项目的 GP3 按负值显示。

### 8.2 交付分析

路径：`/delivery-analysis`。所需权限：`交付分析`。

内容包括：

| 指标 | 口径 |
|---|---|
| 项目总数、合同额、活跃项目、已完成项目 | 截至所选月份月底的累计值 |
| 延期项目 | 已完成延期 + 未完成但已超基线 |
| 平均延期天数 | 已完成项目延期天数 |
| 节点按时率 | 有基线节点中按实际完成日与基线比较；无基线不判定 |
| 成本偏差 | 已审批实际成本与概算成本比较 |
| 交付负荷 | 项目生命周期重叠与金额加权 |
| 利润概览 | 月度概算利润与销售利润 |

部分数据加载失败时，页面顶部显示提示，统计结果可能不完整。

## 9 基础数据

### 9.1 客户管理

路径：`/clients`。所需权限：`客户管理`。

- 客户分为企业客户与子公司。
- 企业客户可查看、编辑；子公司可新增、编辑、删除。
- 客户编码由等级、区域、城市与流水号生成，新增时可调整。
- 客户详情包含联系人、变更历史与历史报价。
- 修改客户名称或销售员时，关联机会、项目、报价、交付与审批中的对应字段同步更新。
- 同一企业名称不可重复。

### 9.2 物料管理

路径：`/materials`。读取权限：`物料管理` 或 `审批管理`；新增与修改需 `新增物料`；审核需 `审批管理`。

物料状态：

| 状态 | 说明 |
|---|---|
| 草稿 | 初始状态 |
| 待审核 | 新建、修改或删除申请已提交 |
| 已通过 | 审核通过 |
| 已驳回 | 审核驳回 |

工作流：

1. 新建或修改物料后进入待审核。
2. 删除操作提交删除申请，不立即删除。
3. 持有 `审批管理` 的用户可通过或驳回。
4. 删除申请通过时才真正删除；被报价引用的物料不可删除。

说明：

- 备注为业务说明，不承载审批标记。
- 审核人不能由提交人自行担任；提交人仅持有 `新增物料` 时看不到审核按钮。

### 9.3 标签管理

路径：`/tags`。写操作需 `新建标签`。

- 标签以树形结构维护，支持新增、重命名、排序、删除。
- 同一父级下不可重名。
- 标签不可移动到自身或自己的子标签下。
- 删除父标签会级联删除全部子标签，操作前须确认。
- 物料通过标签标识分类，标签名称变更后需检查物料引用。

## 10 系统管理

路径：`/settings`。所需权限：`用户管理`、`系统配置` 或 `全部查看权限`。

### 10.1 用户管理

| 操作 | 规则 |
|---|---|
| 新增用户 | 填写姓名、邮箱、职务、密码；密码 8 至 128 位 |
| 编辑用户 | 可修改姓名、邮箱、电话、职务 |
| 启用/停用 | 停用后两个应用均无法登录 |
| 重置密码 | 重置后旧凭证立即失效 |
| 删除用户 | 不可删除自己；不可管理等级高于自己的账号 |

职务变更会同步角色与默认权限；职务为空或不在预设范围时，不改变角色与权限。

### 10.2 权限分配

- 权限以复选方式分配。
- 只能授予自己已持有的权限。
- 不能修改自己的角色与权限。
- 权限为空数组表示有意清空，不会自动回填职务预设。
- `全部查看权限` 为万能权限，授予时须谨慎。

### 10.3 操作日志

- 显示最近 5000 条操作记录，分页浏览。
- 支持按模块筛选。
- 记录登录、审批、用户管理、物料审核、删除等关键操作。

## 11 工时管理

访问路径：`/timerecording/`。适用于工时填报人员、方案/交付经理、总监与管理员。

### 11.1 工时填报

1. 选择周次。
2. 在周一至周日的网格中录入记录。
3. 每条记录填写日期、时段、成本中心、工作内容。
4. 保存。

时段：

| 时段 | 时间 |
|---|---|
| 上午 | 08:00–12:30 |
| 下午 | 13:00–17:30 |
| 晚上 | 18:00–20:30 |

规则：

- 日净工时为 8 小时。
- 结束时间必须晚于开始时间，跨午夜须分两段记录。
- 同一用户同一天的时间段不可重叠。
- 每个时段记录须选择成本中心。
- 请休假单日合计不超过 8 小时；补班日按工作日处理。
- 补录窗口为当前周与前 4 周；超出窗口的周只读。

### 11.2 提交与撤回

| 操作 | 规则 |
|---|---|
| 提交 | 仅本人草稿；同一周整周提交；提交后整周冻结 |
| 批量提交 | 全部记录须为本人草稿且属于同一周 |
| 撤回 | 提交后 30 天内未审核，或审批通过后 30 天内；且记录日期在补录窗口内 |
| 驳回后修改 | 修改后自动回到草稿，可重新提交 |

同一周一旦存在已提交或已审核记录，不可再新增、修改或删除该周记录。

### 11.3 任务规划

- 以 98 天甘特图展示任务。
- 总监、方案经理、交付经理可查看全员任务并分配任务。
- 普通员工仅可查看与维护自己的任务。
- 任务须指定成本中心；部门成本中心不用于任务。

### 11.4 统计

| 页面 | 内容 |
|---|---|
| 个人统计 | 每日堆叠工时、类型分布、开工率 |
| 综合分析 | 工时趋势、成本中心分项、人员对比、开工率等，需经理及以上 |

### 11.5 工时审核

路径：`/timerecording/admin/approval`。需总监或管理员。

- 按人员与周分组审核。
- 可整周通过或驳回。
- 审核结果通知填报人。
- 已审核记录计入统计与成本归集。

## 12 常见问题

| 问题 | 原因与处理 |
|---|---|
| 保存报价后状态变为草稿 | 已通过或已驳回的报价被再次保存，系统按规则要求重新审批 |
| 保存按钮不可用 | 无未保存修改、页面已锁定、正在保存或缺少写权限 |
| 提交按钮不可用 | 存在未保存修改、报价未保存、审批中或已通过、或页面已锁定 |
| 删除设备组后刷新又出现 | 删除需点击保存后才写入数据库；请保存报价 |
| 报价列表金额与机会金额不一致 | 机会金额在报价审批通过后回写；审批中的报价不参与回写 |
| 分析页金额显示「—」 | 缺少可用数据或成本数据不完整 |
| 无法勾选节点 15 完成 | 成本对比未通过，或其余节点未全部完成 |
| 附件上传失败 | 仅支持 PDF，且不超过 3 MB |
| 看不到某个菜单 | 当前账号未被授予对应权限 |
| 登录提示仅限某一应用 | 普通员工仅限工时应用，销售经理仅限预算应用 |
| 历史周无法编辑 | 超出 4 周补录窗口，或该周已提交/已审核 |
| 成本合计与逐项之和不同 | 已删除组项的历史成本键不计入合计，以成本对比表为准 |
