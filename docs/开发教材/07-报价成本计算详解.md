# 07 报价成本计算详解

> **本章学习目标**
> 1. 逐行读懂 `utils/calculations.ts` 的成本/价格/汇总公式；
> 2. 理解含税/未税的**双轨契约**（本项目被审计最多的坑之一）；
> 3. 掌握浮点纪律与"默认值陷阱"（`?? 1` vs `|| 1`）；
> 4. 看懂测试如何用真实数据形状锁定这些函数。

## 7.1 报价编制页面的数据模型（背景）

QuotationPage 的层级是：

```
Project（项目：销售编号/客户名/项目名/范围...）
 └── currentVersion（ProjectVersion：版本号 + 参数 + 汇总）
 └── groups[]（Group：设备组/集成组/包装运输/项目交付/实施费/其他）
      └── items[]（GroupItem：明细项 = 一个物料的成本价格单元）
```

页面上每次编辑（改数量、改单价、加一行）都会触发纯函数重算，把结果写回 state，保存时落库。**这些计算全部集中在 `calculations.ts`，页面不写公式**——这就是"纯函数优先"的体现。

## 7.2 直接成本：calcDirectCost

```ts
/** 直接成本 = 物料成本×数量 + 设计工时×费率 + 装配工时×费率×数量 */
export function calcDirectCost(item: {
  unitCost?: number;
  qtyTotal?: number;
  designHours?: number;
  designHourRate?: number;
  assemblyHours?: number;
  assemblyHourRate?: number;
}): number {
  const materialCost = (item.unitCost || 0) * (item.qtyTotal ?? 1);
  const designCost = (item.designHours || 0) * (item.designHourRate || 0);
  const assemblyCost = (item.assemblyHours || 0) * (item.assemblyHourRate || 0) * (item.qtyTotal ?? 1);
  // 精确到个位（整数）
  return Math.round(materialCost + designCost + assemblyCost);
}
```

逐行讲解：
- **物料成本**：`unitCost × qtyTotal`。`(item.unitCost || 0)`：缺省按 0。
- **数量默认值**：`(item.qtyTotal ?? 1)` —— ⚠️ 注意是 `??`（nullish coalescing）不是 `||`！
  - `?? 1`：只有 `undefined`/`null` 才回退到 1；
  - `|| 1`：**任何 falsy 值都回退到 1**，包括合法的 `0`！
  - 这就是 B1/A1 审计修复：明细数量可以合法地输入 0（且数据库 `qty_total` 没有 `CHECK > 0`），`|| 1` 会把 0 吞成 1，成本虚增为 ×1。用 `?? 1` 后：缺省按 1，显式 0 保留为 0。
- **设计工时费**：`designHours × designHourRate`（不乘数量——设计工作是一次性的）。
- **装配工时费**：`assemblyHours × assemblyHourRate × qtyTotal`（装配按件计，所以乘数量）。
- **取整到个位**：`Math.round(...)`——报价的金额单位到"元"。

**测试锁定**（`tests/calculations.test.ts`）：

```ts
it('qtyTotal=0 合法值不得被吞成 1（物料/装配按 0 计，设计工时费照常）', () => {
  expect(calcDirectCost({ unitCost: 100, qtyTotal: 0 })).toBe(0);
  expect(calcDirectCost({ unitCost: 100, qtyTotal: 0, designHours: 10, designHourRate: 80 })).toBe(800);
});
```

注意测试**直接构造最小对象传入**，没有 mock、没有依赖页面——这就是"真实数据形状直测"。

## 7.3 售价：calcItemPrices

```ts
/**
 * 计算售价（取整到个位）
 * 预期售价 = 直接成本 / (1 - 毛利率)
 * 例：成本100、毛利率35% → 100/(1-0.35) = 153.8
 */
export function calcItemPrices(directCost: number, marginRate: number): { basicPrice: number; accountingPrice: number } {
  const denominator = 1 - marginRate;
  const basicPrice = denominator > 0 ? directCost / denominator : directCost;
  const accountingPrice = Math.round(basicPrice);
  return { basicPrice, accountingPrice };
}
```

要点：
- 售价是"成本加成"反推：已知成本和目标毛利率，求售价 = `成本 / (1 − 毛利)`。
- **分母保护**：`marginRate >= 1` 时 `denominator <= 0`，回退为成本原值（避免除零/负数）。负毛利率（加价卖）也走同一公式：`成本 / (1 - (-0.2))` = 成本/1.2。
- `basicPrice`（浮点，可能 153.846...）与 `accountingPrice`（取整 154）分开返回——展示用 basicPrice（可带小数）还是 accountingPrice（整数）由调用方决定。

## 7.4 成本构成共享计算：computeCostComponents

```ts
/**
 * 成本构成共享计算：全部项次直接成本合计、质保基数、质保/风险/商业费用。
 * ⚠️ calcProjectSummary / computeDeliveryEstGP3 / buildCostLines 三处共用，防口径漂移
 *    （质保基数仅 EQUIPMENT/INTEGRATION 免质保项）。
 */
export function computeCostComponents(groups, version) {
  const totalDirectCost = groups.reduce((s, g) => s + g.items.reduce((si, i) => si + i.directCost, 0), 0);
  const warrantyBase = groups.reduce((s, g) =>
    (g.groupType === 'EQUIPMENT' || g.groupType === 'INTEGRATION')
      ? s + g.items.filter(i => !i.hasWarranty).reduce((si, i) => si + i.directCost, 0)
      : s, 0);
  const warrantyCost = Math.round(warrantyBase * (version.warrantyRate ?? 0));
  const riskCost = Math.round(totalDirectCost * (version.riskRate ?? 0));
  const commercialCost = version.commercialCost ?? 0;
  return { totalDirectCost, warrantyBase, warrantyCost, riskCost, commercialCost };
}
```

这是"**单一来源**"的典型：质保/风险/商业费用的算法只在这里定义一次，被报价汇总、交付概算 GP3、成本对比表三处共用。如果各写各的，改口径时就会漏改、产生"三个页面数对不上"的经典事故。

公式解读：
- **totalDirectCost**：所有组所有明细的 `directCost` 之和。
- **warrantyBase（质保基数）**：只有"设备组/集成组"（EQUIPMENT/INTEGRATION）里 `hasWarranty=false` 的明细才算进基数——带质保的项（如外购成品）不重复计提。
- **warrantyCost**：`warrantyBase × warrantyRate`（默认 1%）。
- **riskCost**：`totalDirectCost × riskRate`（默认 3%）。
- **commercialCost**：商业费用，直接取版本参数值（不按比例）。

## 7.5 版本汇总：calcProjectSummary（最复杂的函数）

```ts
export function calcProjectSummary(groups, version, discountedPriceUntaxed?: number): ProjectSummary {
  // ① 质保/风险/商业费用走共享计算
  const { totalDirectCost, warrantyBase, warrantyCost, riskCost, commercialCost } = computeCostComponents(groups, version);
  let totalAccountingPrice = 0, materialCost = 0, laborCost = 0, projectExpense = 0;

  // ② 按组类型分解料/工/费
  for (const group of groups) {
    for (const item of group.items) {
      totalAccountingPrice += item.accountingPrice;
      const mat = Math.round((item.unitCost || 0) * (item.qtyTotal ?? 1));
      const lab = item.directCost - mat;
      if (group.groupType === 'PROJECT_DELIVERY') {
        laborCost += item.directCost;                       // 项目交付组：整行算人工
      } else if (group.groupType === 'PACKAGING_TRANSPORT' || group.groupType === 'IMPLEMENTATION_EXPENSE' || group.groupType === 'OTHER') {
        projectExpense += item.directCost;                  // 包装运输/实施费/其他：整行算项目费用
      } else {
        if (mat > 0) materialCost += mat;                   // 设备/集成组：物料+人工分开
        if (lab > 0) laborCost += lab;
      }
    }
  }

  // ③ 折扣率
  const discountedPriceV = (discountedPriceUntaxed && discountedPriceUntaxed > 0) ? discountedPriceUntaxed : totalAccountingPrice;
  const discountRate = totalAccountingPrice > 0 ? (totalAccountingPrice - discountedPriceV) / totalAccountingPrice : 0;

  // ④ 含税转换
  const taxRate = version.taxRate ?? TAX_RATE;
  const totalCost = totalDirectCost + warrantyCost + riskCost + commercialCost;
  const totalAccountingPriceTax = Math.round(totalAccountingPrice * (1 + taxRate));
  const discountedPriceTax = Math.round(discountedPriceV * (1 + taxRate));
  const totalCostTax = Math.round(totalCost * (1 + taxRate));

  // ⑤ GP3 利润率
  const gp3 = discountedPriceTax > 0 ? (discountedPriceTax - totalCostTax) / discountedPriceTax : 0;

  return {
    totalDirectCost, warrantyBase, warrantyCost, riskCost, commercialCost, totalCost,
    totalAccountingPrice: totalAccountingPriceTax,          // ← 含税
    discountedPrice: discountedPriceTax,                    // ← 含税
    discountRate, gp3,
    gp3Amount: Math.round(discountedPriceTax * gp3),
    materialCost, laborCost, projectExpense,
  };
}
```

**逐块讲解**：

**② 料/工/费分解**（按组类型决定归属）：
| group_type | materialCost | laborCost | projectExpense |
|---|---|---|---|
| EQUIPMENT / INTEGRATION | 物料部分（mat） | 人工部分（lab=directCost−mat） | — |
| PROJECT_DELIVERY | — | 整行 | — |
| PACKAGING_TRANSPORT / IMPLEMENTATION_EXPENSE / OTHER | — | — | 整行 |

这样管理层能看到"这个报价里物料多少钱、人工多少钱、其他费用多少钱"。

**③ 折扣率**：`(总售价 − 折后价) / 总售价`。如果没传折后价，就用总售价（不打折）。

**④ 含税转换** —— ⚠️ **这是全项目最容易踩的坑（B7 契约定稿）**。请记住这张表：

| 量 | 口径 |
|---|---|
| 明细行（group_items）的成本/价格 | **未税** |
| `project_versions` 列的 `discounted_price` | **持久化含税** |
| `calcProjectSummary` **输入**的 `discountedPriceUntaxed` | **必须未税**（页面用 `exAmount(含税值, taxRate)` 转换） |
| `calcProjectSummary` **输出**的 `totalAccountingPrice`/`discountedPrice` | **含税** |
| 报价汇总展示（预期总价/折后报价） | 含税 |

所以这个函数里 `总售价 ×(1+税率)` 转含税是**故意的**。新接手者最常犯的错是：按"明细未税"的印象，以为返回的总价也是未税，然后**再乘一次税 → 双重计税**。测试锁定的就是"输入未税、输出含税"这个契约。

**⑤ GP3**：`(含税售价 − 含税总成本) / 含税售价`。`totalCostTax` 也乘了税——因为收入含税，成本也要含税才能同口径比。

## 7.6 交付概算 GP3：computeDeliveryEstGP3

```ts
export function computeDeliveryEstGP3(contractAmount, groups, version?) {
  const taxRate = version?.taxRate ?? TAX_RATE;
  const exTax = Math.round(contractAmount / (1 + taxRate));     // 合同额未税
  const { totalDirectCost: totalEstimated, warrantyCost, riskCost, commercialCost } = computeCostComponents(groups, version ?? {});
  const grandEstimated = totalEstimated + riskCost + warrantyCost + commercialCost;   // 概算总成本
  const estGP3 = exTax > 0 ? (exTax - grandEstimated) / exTax : 0;
  return { exTax, totalEstimated, warrantyCost, riskCost, commercialCost, grandEstimated, estGP3 };
}
```

- 交付阶段：合同额（含税）已知 → 未税 = `合同额 / (1+税)`；
- 概算成本 = 报价时的直接成本 + 质保 + 风险 + 商业费用；
- 概算 GP3 = `(合同额未税 − 概算总成本) / 合同额未税`。
- 这个值用于交付成本对比（概算利润率 vs 实际利润率）。

## 7.7 两个小工具：formatMoney 与 rateToPercent

```ts
/** 格式化金额（整数） */
export function formatMoney(value, locale = 'zh-CN'): string {
  return Math.round(value ?? 0).toLocaleString(locale);
}

/** 费率（小数）→ 百分比数值（0.35 → 35） */
export function rateToPercent(v: number): number {
  return Math.round(v * 10000) / 100;
}
```

- `formatMoney`：千分位展示（`150000` → `150,000`）。
- `rateToPercent`：`0.35` → `35`。⚠️ 注意 `Math.round(v*10000)/100` 而不是 `v*100`——为了去掉浮点噪声（`0.345 × 100 = 34.4999999...`）。这两个函数是"全项目散落 10 处/6 处重复实现"收敛出来的单一来源（F08 修复）。

## 7.8 本章小结

- 成本模型：物料×量 + 设计工时×费率 + 装配工时×费率×量 → direct_cost。
- 售价 = 成本 / (1 − 毛利率)；汇总含质保/风险/商业费用。
- **含税/未税双轨**：明细未税、列持久化含税、汇总输出含税——`calcProjectSummary` 的输入输出口径被测试锁定。
- 浮点纪律：聚合后 round；`?? 1` 而非 `|| 1`。
